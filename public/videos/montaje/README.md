# Videos Explicativos de Montaje Paso a Paso

Colocar aquí los videos explicativos en formato MP4 correspondientes a cada tipología de tinglado:

- `2-aguas.mp4`: Video explicativo de montaje para tinglados a dos aguas (reticulado, pórtico y varillas).
- `1-agua.mp4`: Video explicativo de montaje para tinglados a un agua.
- `2-aguas-portico.mp4` (opcional específico para pórtico).
- `2-aguas-varillas.mp4` (opcional específico para varillas).
- `1-agua-varillas.mp4` (opcional específico para 1 agua en varilla).
